# 🌏 ExploreSEAsia

[Live Website](https://explore-se-asia.web.app/) | [Client Repository](https://github.com/kawsar12759/explore-se-asia/tree/main/explore-se-asia-client) | [Server Repository](https://github.com/kawsar12759/explore-se-asia/tree/main/explore-se-asia-server)

**ExploreSEAsia** is a travel-focused web application that helps users discover beautiful destinations across Southeast Asia. Whether you're planning a vacation, looking for cultural landmarks, or just want to explore hidden gems, this platform provides an interactive and informative experience.

---

## 🛠️ Tech Stack

### Frontend
- React.js
- React Router
- Tailwind CSS
- DaisyUI
- Firebase Hosting & Authentication

### Backend
- Node.js
- Express.js
- MongoDB
- Firebase Admin SDK
- CORS, Dotenv

---

## ✨ Features

- 🔍 **Explore Destinations**: View and search tourist spots across Southeast Asia.
- ➕ **Add Your Favorite Spot**: Authenticated users can add new destinations.
- 📌 **Details Page**: View detailed information about each place.
- 🔒 **User Authentication**: Sign up, log in, and protect routes using Firebase Auth.
- ⭐ **Favorite Spots**: Logged-in users can mark places as favorites.
- 🌐 **Responsive Design**: Fully responsive on mobile, tablet, and desktop.

## 🔧 Setup Instructions

### Prerequisites
- Node.js and npm
- MongoDB (local or cloud)
- Firebase project

### Clone the Project
```bash
git clone https://github.com/kawsar12759/explore-se-asia.git
cd explore-se-asia
```

### Client Setup
```bash
cd explore-se-asia-client
npm install
npm run dev
```

### Server Setup
```bash
cd explore-se-asia-server
npm install
# Create a .env file with your Mongo URI, and Firebase credentials
npm start
```
